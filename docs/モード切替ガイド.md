# kabu-auto 取引モード切替ガイド

`switch-mode.bat` を使って、ペーパー（仮想取引）と本番（実発注）を安全に切り替える手順。

---

## 1. モードの種類

| モード | 実発注 | 実口座API読取 | 用途 |
|--------|:---:|:---:|------|
| `paper` | × | ×（価格は yfinance） | 仮想取引。終値で即時シミュレート |
| `dry_run` | × | ○ | 実口座の板/余力は読むが発注しない検証 |
| `semi_live` | ○（承認後） | ○ | 承認キューに積み、ダッシュボードで承認した分だけ発注 |
| `live` | ○ | ○ | **本番。実資金で実発注** |

**推奨の移行順**: `paper` → `dry_run` → `semi_live` → `live`

---

## 2. 使い方（かんたん・GUIメニュー）

1. プロジェクト直下の **`switch-mode.bat` をダブルクリック**する。
2. 現在のモードと接続先が表示される。番号でモードを選ぶ。

   ```
   現在: paper （接続先: 18081 / パスワード: 検証用）

     [1] paper      ペーパー（仮想取引・発注なし）※実口座から隔離
     [2] dry_run    ドライラン（実口座読取・発注なし）
     [3] semi_live  セミライブ（承認後に実発注）
     [4] live       本番（実資金で実発注）
     [Q] 終了
   ```

3. `live` / `semi_live` を選ぶと、確認のため **`yes` の入力**を求められる。
   （`no` などを入力すればキャンセルされ、モードは変わらない。）
4. 切替後、`今すぐ python main.py を起動しますか？ (y/N)` と聞かれる。
   - `y`: そのまま起動する（`live` / `semi_live` は `CONFIRM_LIVE_TRADING=true` を自動設定）。
   - `N`: 切替のみ。起動は任意のタイミングで手動で行う。

### 本番へ切り替える最短手順
`switch-mode.bat` → `4` → `yes` → `y`

### ペーパーに戻す最短手順
`switch-mode.bat` → `1` → `y`（または `N` で切替のみ）

---

## 3. 自動でやってくれること

モードを選ぶと、以下を**まとめて整合**させる（手作業の編集ミスを防ぐ）。

| 選択 | `trading.mode` | `base_url` | `.env` のパスワード |
|---|---|---|---|
| `paper` | `paper` | **18081（検証）** | 検証用 |
| `dry_run` / `semi_live` / `live` | 各モード | **18080（本番）** | 本番用 |

- `paper` は検証系（18081）へ隔離し、実口座に触れない構成にする。
  `paper` の日足価格は yfinance から取得するため、検証環境（kabuステーション）が
  停止していても支障なく動作する。
- 編集前に `config.yaml.bak` / `.env.bak` を自動作成する。切替を取り消したいときは
  この `.bak` を元に戻せばよい。

### パスワードの持ち方（重要）

切替スクリプトは **APIパスワードの値を持たない**。`.env`（`.gitignore` 済み）に本番用・検証用の
2つを定義しておくと、モードに応じてどちらを使うかを選び、`KABU_API_PASSWORD` へコピーする。

```dotenv
KABU_API_PASSWORD=            # アプリが実際に読む値（スクリプトが上書きする）
KABU_API_PASSWORD_LIVE=       # 本番系（dry_run / semi_live / live）
KABU_API_PASSWORD_VERIFY=     # 検証系（paper）
```

- 未定義でも動作する。その場合はモードと接続先だけを切り替え、`KABU_API_PASSWORD` は
  変更せずに警告を表示する（誤って空パスワードにして起動不能になるのを防ぐため）。
- **APIパスワードの平文は `.env` にのみ置くこと。** スクリプト・`config.yaml`・ドキュメント・
  コメントに値を書き写すと、リポジトリを公開した際にそのまま漏洩する。

## 4. 非対話（バッチ / 自動化）

メニューを出さずに切り替える。

```powershell
# 切替のみ（起動しない）
powershell -File scripts\switch_mode.ps1 -Mode paper -NoLaunch

# 切替して起動（paper / dry_run のみ。live / semi_live は誤起動防止のため自動起動しない）
powershell -File scripts\switch_mode.ps1 -Mode dry_run
```

`-Mode` に指定できる値: `paper` / `dry_run` / `semi_live` / `live`

---

## 5. 注意点

- **反映には kabu-auto の再起動が必要**。起動時に一度だけ `config.yaml` を読むため、
  稼働中のプロセスには影響しない（切替後に再起動して初めて有効になる）。
- 実発注モードは起動時に**プリフライトチェック**（API疎通・未解決注文・ポート・
  検証ポート誤指定・取引停止スイッチ）が走り、致命的な問題があれば起動を中断する。
  詳細は [README](../README.md) の「取引モード」章を参照。
- リスクパラメータ（`max_positions` など）はアクティブな `risk_profile` の値で
  上書きされる。本番前に想定どおりか確認すること。
